# homelab

A Kubernetes lab on one Proxmox host: three Talos Linux nodes, Flux, Cilium,
services reachable over Tailscale. Used to run a few applications and to
practise PostgreSQL operations with CloudNativePG.

Documentation: <https://msavdert.github.io/homelab/> (source in `docs/`).
Start with `docs/index.md`. Agents start with `AGENTS.md`.
